# CompassCAD

Hey there! This is our new home for all things CompassCAD, now happily owned by [Boowat](https://github.com/boowat) (which now, the [original author of CompassCAD](https://github.com/zeankundev) works in)!

With this, as a separate organization for all things CompassCAD, we would proudly create new updates efficiently, as well as focusing to our long-term commitment of making CAD easy for everyone.

Here, you can find active projects, as well as scrapped variants of CompassCAD!

## Contribution guidelines
If you want to contribute, you can! It's easy, just:
- Create a fork, write your changes, and push yor fork.
- Create a pull request at one of our upstream projects
- State your changes in detail, and why, and how does it affect the UX to the user
- Wait for one of our representatives to come in, view your PR changes. Once that is done, if all checks out, we will merge your PR and make your changes upstream!

Exceptions for all of this only apply specifically for `zeankundev` because he has all direct pushing rights to `origin/main` (and the project lead).

## Repositories
- `NextDesktop`: The CompassCAD NEXT desktop app
- `ReactWeb`: The CompassCAD NEXT web app, for both desktop and mobile. Accessible via [https://compass-cad.web.app](https://compass-cad.web.app)
- `Mobile`: Scrapped version of CompassCAD NEXT, built specifically for mobile platforms.
